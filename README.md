# Orbit — Freelancers OS

Orbit is a polished, local-first business command center for freelancers. It brings projects, daily tasks, invoices, revenue visibility and client proposals into one responsive workspace.

## Features

- Project pipeline with progress and value tracking
- Daily focus list with completion controls
- Invoice tracker with Paid, Pending and Overdue states
- Revenue, pipeline, task and collection metrics
- Client-ready proposal generator with one-click copy
- PKR-first formatting for Pakistani freelancers
- Persistent browser storage—no account, database or subscription required
- Responsive UI, PWA metadata, automated tests and GitHub Pages deployment

## Run locally

```bash
npm run check
npm test
npm run build
npx serve dist
```

All data is stored only in the current browser using `localStorage`.
